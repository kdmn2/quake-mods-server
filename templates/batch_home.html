2. Import from server folder

This lists packages in a folder on the server / container, not on your own computer. Folders must be configured by the administrator (IMPORT_ROOTS, normally a read-only mount at /imports). Files are only read, never changed, moved or deleted. Scanning only lists files; nothing is imported until you select files and confirm.
