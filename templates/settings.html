Re-encode TGA images as PNG (lossless, verified identical pixels)

Only truecolor TGAs whose PNG conversion can be *verified byte-for-byte identical after decoding* are converted; anything the verifier cannot prove identical stays TGA. Ironwail loads .png before .tga with the same decoder, so converted files are indistinguishable in the engine. Side effect: the package bytes change.
