Overlong entry names

A Quake PAK entry name can be at most 55 bytes (Ironwail's dpackfile_t.name[56]). Entries whose final path is longer than that cannot be represented. By default this importer omits such entries and records each exclusion in the conversion report, so a single overlong asset (typically an album-art image with embedded UUIDs or another third-party blob) does not block an otherwise usable release. Untick to keep the strict rejection — the package will be refused unless the path fits.

Even with skipping on, missing required assets may affect gameplay — review the conversion report and load the package in Ironwail before publishing.

Re-encode TGA images as PNG (lossless)

Ironwail decodes TGA and PNG with the same library and always to RGBA, so a PNG with identical pixels looks exactly the same in game. Each image is decoded again after conversion and compared byte for byte; anything that cannot be proven identical, or would not get smaller, stays a TGA. The package bytes change (only the image files) and the result depends on the Pillow/zlib versions, which are recorded. Only 24/32-bit uncompressed or RLE TGAs are converted.
