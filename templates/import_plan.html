Re-encode TGA images as PNG (lossless)

Ironwail decodes TGA and PNG with the same library and always to RGBA, so a PNG with identical pixels looks exactly the same in game. Each image is decoded again after conversion and compared byte for byte; anything that cannot be proven identical, or would not get smaller, stays a TGA. The package bytes change (only the image files) and the result depends on the Pillow/zlib versions, which are recorded. Only 24/32-bit uncompressed or RLE TGAs are converted.
